# 📊 Análise Financeira — Power BI

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte da minha prática em **Power BI e análise de dados**, com o objetivo de transformar dados financeiros em informações visuais para facilitar a análise e a tomada de decisão.

O dashboard apresenta uma visão geral de **receitas, despesas e resultados financeiros**, permitindo analisar os valores ao longo do tempo e por diferentes componentes.

## 🎯 Objetivos

- Analisar o total de receitas e despesas;
- Comparar receitas e despesas ao longo dos anos;
- Identificar os principais componentes financeiros;
- Criar indicadores para facilitar a interpretação dos dados;
- Desenvolver uma visualização clara e interativa no Power BI.

## 🛠️ Ferramentas utilizadas

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Microsoft Excel**

## 📈 Principais análises

O dashboard permite visualizar:

- Total de receitas;
- Total de despesas;
- Resultado financeiro;
- Evolução dos valores por ano;
- Distribuição por componente;
- Comparação entre receitas e despesas.

## 💡 Principais aprendizados

Durante o desenvolvimento, pratiquei conceitos de:

- Tratamento e transformação de dados;
- Modelagem de dados;
- Criação de medidas DAX;
- Criação de indicadores e gráficos;
- Organização de dashboards;
- Análise e interpretação de informações financeiras.
